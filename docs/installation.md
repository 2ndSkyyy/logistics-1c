# Установка из исходников

## Что понадобится

Использовавшееся окружение: учебная платформа 8.3.27.1508, учебная Бухгалтерия 3.0.67.54, Windows, файловый режим. Проверка развёртывания именно этого подготовленного комплекта с нуля ещё требуется. Типовая Бухгалтерия не входит в репозиторий.

Для проверки используйте две отдельные учебные базы. Если обновляете существующие базы с документами, сначала сохраните их резервные копии. Загрузка конфигурации логистики заменяет конфигурацию выбранной базы, поэтому эту операцию выполняют только в предназначенной для логистики базе.

## База «Управление логистикой»

1. В списке запуска 1С нажмите «Добавить» → создание новой информационной базы → создание без конфигурации. Выберите отдельную папку.
2. Откройте её в конфигураторе. При необходимости выполните «Конфигурация → Открыть конфигурацию».
3. Выполните «Конфигурация → Загрузить конфигурацию из файлов…», указав каталог `src/logistics`, содержащий `Configuration.xml`. Загружайте весь комплект файлов.
4. Сохраните конфигурацию, выполните проверку конфигурации и обновите конфигурацию базы данных клавишей F7. Просмотрите список предлагаемых изменений.
5. Запустите 1С:Предприятие. Проверьте наличие справочников, документа «Заявка», отчёта «Оплата заявок» и обработки «Обмен JSON с Бухгалтерией».
6. Заполните учебные справочники и заявку по [сценарию](user-guide.md).

## Расширение в Бухгалтерии

1. Разверните отдельную учебную Бухгалтерию 3.0.67.54 из установленного шаблона. Откройте её конфигуратор.
2. Откройте «Конфигурация → Расширения конфигурации».
3. Для новой установки добавьте расширение с именем `ЛогистикаОбмен`, назначением «Дополнение» и префиксом `ЛГ_`. При обновлении используйте существующее расширение, не удаляйте его вместе с данными.
4. Выделите расширение. Используйте меню **«Конфигурация» внутри окна списка расширений**, выберите загрузку конфигурации из файлов и укажите `src/bp-extension`. Не загружайте эти файлы в основную конфигурацию Бухгалтерии.
5. Откройте дерево расширения и убедитесь, что имя — `ЛогистикаОбмен`; в нём есть `ЛГ_Заявка`, `ЛГ_ОбменJSON` и заимствованный `СчетНаОплатуПокупателю`.
6. Сохраните расширение, обновите конфигурацию базы данных и выполните проверку возможности применения расширений. Перезапустите клиент Бухгалтерии.
7. Проверьте раздел «Логистика»: заявки на перевозку и обработка «Обмен JSON с логистикой».

В использовавшейся учебной базе заполнение счёта через расширение заработало после отключения безопасного режима **для данного расширения**. Эта настройка не следует из XML и не является универсальным требованием для всех конфигураций. При повторении учебного окружения проверьте её, если обработчик не вызывается; параметры безопасности типовой конфигурации целиком не изменяйте.

## Обновление существующей учебной копии

Исправления телефона, email и обработчика логиста уже включены в исходники и проверены автором 28.09.2026. Логистика повторно выгружена средствами 1С; её `ConfigDumpInfo.xml` обновлён. [История исправлений](prepublication.md).

Для первого развёртывания используйте полную загрузку каталога исходников. При обновлении базы сохраните резервную копию и проверьте предлагаемые изменения. Если `Сотрудники.Телефон` раньше имел тип ссылки на отдел, заранее проверьте значения: ссылки не являются телефонными номерами.

## Быстрая проверка установки

- Выбор логиста заполняет его отдел; очистка логиста очищает отдел.
- Телефон сотрудника принимает текст, электронная почта контрагента длиннее 10 символов сохраняется целиком.
- В обеих обработках можно выбрать сохранённую заявку и открыть её.
- Полный обмен и создание счёта проходят по [testing.md](testing.md).

У исходной учебной заявки UUID фиксирован в примерах. У новой заявки будет другой UUID. Не пытайтесь загрузить готовый обратный пример в произвольную новую заявку: отказ в таком случае предусмотрен защитой связи.
