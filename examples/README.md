# Примеры обмена

Два файла получены из учебных баз, содержат вымышленные данные и включены без изменения содержимого.

- [Логистика_Заявка_тест.json](Логистика_Заявка_тест.json) — заявка стоимостью 50 000 из логистики в Бухгалтерию.
- [БП_Результат_тест.json](БП_Результат_тест.json) — ответ: один счёт на 50 000, одна банковская оплата 20 000, остаток 30 000.

Связанные UUID принадлежат исходной паре учебных баз. В новом экземпляре базы создайте свою заявку и выполните весь цикл выгрузки/загрузки: готовый ответ не предназначен для привязки к произвольному новому документу.

Скрипт [check_project.py](../tools/check_project.py) проверяет согласованность этих двух примеров; он не загружает их в 1С. Полное описание — [json-format.md](../docs/json-format.md).
