# Управление логистикой на 1С

Учебный проект: заявки на перевозку, создание счетов в «Бухгалтерии предприятия» и возврат сведений об оплатах через JSON-файлы. Реализованы самостоятельная конфигурация, расширение Бухгалтерии и отдельная обработка обмена в каждой базе.

**Состояние:** версия для демонстрации и проверки перед первым выпуском. Сквозной сценарий проверялся вручную в учебных базах; при подготовке репозитория исправлены три небольшие ошибки. Для этих исправлений и установки из XML требуется контрольный запуск в 1С — [порядок проверки](docs/prepublication.md).

![Отчёт об оплатах: стоимость 50 000, оплачено 20 000, остаток 30 000](docs/screenshots/report-partial.png)

## Возможности

- Заявка с заказчиком, договором, логистом, отделом, маршрутом, водителем и транспортом.
- Расчёт сумм без НДС, разницы стоимости перевозки и суммы исполнителя, оплаты и остатка.
- Проверка порядка дат маршрута и принадлежности договора заказчику в логистике.
- Таблицы бухгалтерских документов, оплат, почтовых отправлений и работы с задолженностью.
- Передача заявки в Бухгалтерию и создание счёта с явной ссылкой на заявку.
- Получение проведённых банковских поступлений, распределённых на связанные счета.
- Обратный обмен полным снимком: текущие счета и оплаты заменяют предыдущий набор строк.
- Отчёт СКД «Оплата заявок» с периодом, группами оплаты и итогами по отделам.

## Две базы и два направления

| Где | Объект | Действия |
|---|---|---|
| Управление логистикой | `Обработка.ОбменJSON` | Выгрузить заявку; загрузить результат; открыть заявку |
| Бухгалтерия, расширение «ЛогистикаОбмен» | `Обработка.ЛГ_ОбменJSON` | Загрузить заявку; обновить оплаты; выгрузить результат; открыть заявку |

Сохранённую заявку пользователь выбирает явно. Обработка не создаёт заявки автоматически. Контрагента, организацию и договор в Бухгалтерии пользователь сопоставляет вручную. Связь заявок хранится по UUID, связь счёта с заявкой — в реквизите `ЛГ_ЗаявкаОснование`.

## Окружение

| Компонент | Использовался при разработке |
|---|---|
| Платформа | 1С:Предприятие, учебная версия 8.3.27.1508 |
| Бухгалтерия | Бухгалтерия предприятия (учебная), 3.0.67.54 |
| Режим | Файловые базы, управляемое приложение, Windows |
| Формат исходников | Иерархическая выгрузка XML и модули BSL |

Совместимость с другими релизами Бухгалтерии, веб-клиентом и серверной базой отдельно не проверялась. Платформа и типовая Бухгалтерия устанавливаются отдельно.

## Состав репозитория

| Путь | Содержимое |
|---|---|
| `src/logistics` | Самостоятельная конфигурация «УправлениеЛогистикой» |
| `src/bp-extension` | Только расширение «ЛогистикаОбмен», включая описания заимствованных объектов |
| `examples` | Два реальных файла учебного обмена с вымышленными данными |
| `docs` | Инструкции, история решений, проверки и скриншоты |
| `tools/check_project.py` | Проверка структуры поставки без запуска 1С |

Исходная типовая Бухгалтерия, её дистрибутив, базы `.1CD` и резервные копии `.dt` в проект не включены. XML содержит конфигурацию, но не заполненные справочники и документы. Примеры JSON привязаны к UUID исходных учебных документов; для новой пары баз файлы нужно сформировать заново.

## Границы текущей версии

Обрабатываются счета покупателям и банковские поступления; кассовые оплаты, возвраты, реализации и валютный пересчёт не реализованы. Обновление оплат полностью заменяет таблицу банковскими данными, включая удаление вручную добавленных строк. Период отчёта отбирает **даты заявок**, а суммы отражают **текущее** состояние оплаты, не задолженность на конец периода.

В расширении логист, отдел, водитель, тягач и прицеп хранятся строками. Это упрощение относительно требования о соответствующих типах данных отдельно отмечено в [сверке с заданием](docs/requirements.md). Старые кнопки обмена в формах документов сохранены; основной сценарий описан через обработки.

## Проверка файлов

Из корня репозитория при установленном Python 3:

```console
python tools/check_project.py
```

Скрипт проверяет XML, связи обработчиков форм, состав метаданных, согласованность JSON-примеров и локальные ссылки документации. Он не компилирует BSL и не заменяет проверку в 1С. Результаты подготовки — [verification.json](docs/verification.json).

Лицензия для авторского кода пока не выбрана; файл `LICENSE` не добавлен. Репозиторий предназначен для демонстрации учебной разработки.
